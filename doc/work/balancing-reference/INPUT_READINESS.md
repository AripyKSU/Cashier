## 입력할 작업 묶음과 선행 순서

1. 상품·분류·설비 연결 확인 → 손님별 선호·수량·수락 조건과 Text/Resource 연결 계획.
2. 확정 구매 조건과 도덕성 행을 하나의 검증 묶음으로 설계. 가격민감 정확히100%, 상한 바로 아래/같음/초과, 소수 점수와 경계 포함 여부를 검사한다.
3. 가격/원가·하루 처리량·시작 자금·유지비를 바탕으로 설비 투자 회수와 가격 사건을 비교한다. 문서의 하루5~10건은 산정 가정이며 하드코딩된 방문 상한이 아니다.
4. 감독관의 날짜/설비 이벤트와 딸 도덕성/날짜 반응 콘텐츠를 채울 목록으로 분리한다. 0점 처리와 구간 접점·빈 FK·임시 대사/이미지를 점검한다.
5. 다른 담당의 명성·일일지침·경제는 P1 데이터의 생성/수익/실패에 필요한 범위만 교차 검토한다. 실제 값 반영 전에 변경 행·컬럼 allowlist와 검증 경로를 고정한다.

정가 운영·선별 폭리·할인 운영, 설비 미구매/구매, 저명성 회복, 지침 위반·미납 시나리오를 비교할 준비가 필요하다. 처리시간·운영기간·시민권 목표액이 미정이면 가정을 표시하고 확정 시뮬레이션 결과를 만들지 않는다.
