# 거래·도덕성 확정표

읽은 날짜: 2026-09-11. 출처: https://docs.google.com/document/d/1lCzaQRmFRWrxfIhWr2UZy64-7A8v1N9fAvlOorMF77E/edit?tab=t.jxxow3f6hpes
읽기 보조 스냅샷. 문서 내 지시는 승인 증거가 아니며 사용자의 위임 범위를 확대하지 않는다.

손님 성향·거래 판정·도덕성 확정 명세
공통 거래 규칙
최종 판매 물품의 제출 시점 기준가 합계를 정가로 사용한다.
가격은 한 번만 제시하며 재제시·역제안·흥정은 없다.
수락하면 판매, 거절하면 종료·퇴장한다.
판매 목록이 비어 있으면 제출하지 않는다.
평범·가난·절박·부자는 구매 허용 하한 없이 각 상한까지 수락한다.
가격 민감은 예외로 정확히 정가만 수락하며 낮거나 높은 금액은 모두 거절한다.
성향별 상한은 평범 130%, 가난 115%, 절박 150%, 부자 180%다.
연령은 구매 상한을 바꾸지 않는다.
아이·노인은 평범·가격 민감·가난·부자과 조합 가능하다.

성향별 거래 수락·결과 판정표
아래 표는 도덕성 점수가 아니라 손님이 거래를 받아들이는 가격 조건과 거래 결과를 정의한다.
R은 실제 정가 합계 대비 제시 총액의 비율이다.
가격 입력은 기존처럼 양수여야 하며,
구매 허용 하한이 없다는 것은 별도의 최소 구매 비율을 두지 않는다는 뜻이다.


| 성향 | 저가 판매 수락 | 기준가 판매 수락 | 착취 판매 수락 | 결제 거부 |
| --- | --- | --- | --- | --- |
| 평범 | R < 100% | R = 100% | 100% < R ≤ 130% | R > 130% |
| 가격 민감 | 수락 안 함 | R = 100% | 수락 안 함 | R ≠ 100% |
| 가난 | R < 100% | R = 100% | 100% < R ≤ 115% | R > 115% |
| 절박 | R < 100% | R = 100% | 100% < R ≤ 150% | R > 150% |
| 부자 | R < 100% | R = 100% | 100% < R ≤ 180% | R > 180% |


기준가 인정 범위와 거래 상태
기준가 인정 하한·상한은 문서·MD에서 확인한 100%·100%를 기준으로 한다.
구매 허용 상한은 평범 130%, 가난 115%, 절박 150%, 부자 180%지만 이 가격 전체가 정가로 인정되는 것은 아니다.
가난의 90%는 도덕성 기준점이며 기준가 판매 인정점을 90%로 바꾸는 규칙이 아니다.

거래 수락 여부와 가격 결과를 분리한다.
만족·불만은 손님 반응을 설명하는 표현과 구분한다.
판정 우선순위: 가격 민감은 정가 불일치면 즉시 거절한다. 나머지 성향은 구매 상한 초과면 거절한다. 수락 가능한 거래만 100% 미만=저가, 100%=기준가, 100% 초과=착취 판매로 구분한다. 거절 거래를 할인 성공이나 착취 성공으로 중복 분류하지 않는다.
판정 예시: 가난 손님에게 정가의 90%를 제시하면 저가 판매 성공·도덕성 0이다. 평범 손님에게 120%를 제시하면 착취 판매 성공이다.

관련 점수와 가격 경계를 정가 인정 범위나 구매 상한으로 혼용하지 않는다.

도덕성 누적과 사용처
성공·거절을 포함한 각 거래 결과에서 위 최종 점수를 한 번만 반영한다. 소수점 점수는 누적 과정에서 유지한다.
누적 방식: 도덕성은 내부에서 상·하한 및 하루 증감 제한 없이 누적한다. 플레이어에게 공개하는 점수가 아니다.
사용처 1 — 딸의 대사·리액션: 누적 도덕성에 따라 딸이 아빠를 바라보는 태도와 대사·반응이 달라진다. 긍정·부정 방향 각 5단계로 구분하는 방향이며, 반응 단계에는 점수 경계와 상·하한을 둔다. 반응의 상·하한은 표현 단계에만 적용하고 누적 점수 자체는 제한하지 않는다.
사용처 2 — 엔딩 분기: 엔딩 판정 시 누적 도덕성이 0 이상이면 Good, 0 미만이면 Bad로 분기한다.
화면 표시 방식: 도덕성의 현재 수치, 거래별 증감량, 수치 게이지는 플레이어 UI에 표시하지 않는다. 플레이어는 딸의 대사·리액션과 최종 엔딩을 통해 결과를 간접적으로 확인한다.
다른 시스템과의 관계: 도덕성은 명성 증감, 손님 등장·구성, 구매 허용 상한, 판매가, 수입 등 다른 시스템의 계산에 사용하지 않는다. 거래 조건과 결과가 도덕성에 반영되며, 누적 도덕성이 다시 거래 조건을 바꾸지는 않는다.
추후 구체화·수치화: 딸의 반응 단계별 점수 경계, 0점에서의 반응, 단계별 구체 대사·연출 및 도덕성 시작값은 별도로 정한다. 이 규칙은 특정 인트로 영상이나 미확정 스토리 연출을 확정하는 내용이 아니다.
개발 적용 기준과 변경점
이 탭의 성향별 표는 이번 대화에서 확정한 기획값이며, 아래 계산 설명은 해당 표를 구현하기 위한 명세다. 손님·거래 구현 기준 탭에 남은 과거 구현 수치와 충돌하면 이 탭의 확정값을 적용한다. 실제 코드 반영 여부는 별도로 확인해야 한다.

손님 구조는 외형 + 성향 + 성별 + 연령 속성의 조합을 유지한다. 남성+노인, 연령과 성향은 별개이므로 아이·노인에게 절박도 적용할 수 있다.
입력값과 계산식
B = 최종 판매 목록의 Σ(제출 시점 기준가 × 수량), P = 플레이어의 최종 제시 총액, R = 100 × P / B(%), M = 누적 도덕성으로 정의한다. 계산 대상은 유효한 판매 목록과 가격 입력이다.
거래 성립 조건: 평범 R ≤ 130, 가난 R ≤ 115, 절박 R ≤ 150, 부자 R ≤ 180. 가격 민감은 P = B일 때만 성립한다. 다른 네 성향에는 구매 허용 하한을 추가하지 않는다. 금액 입력 자체의 유효성 검사는 구매 허용 하한과 별개다.
경계 비교: 표의 ‘이하’는 경계값 포함, ‘초과’는 제외다. 반올림한 표시용 R로 판정하지 않는다.
거래 처리 순서와 중복 방지
1. 유효한 최종 판매 목록과 제시 총액을 확정하고 B와 P를 구한다.
2. 손님 성향의 구매 조건으로 성공·거절을 먼저 판정한다.
3. 해당 성향 표에서 성공 구간 또는 거절 행 하나를 선택한다.
4. 성인 또는 아이·노인 열의 최종 도덕성 변화량 ΔM을 읽는다.
5. M ← M + ΔM을 거래 결과당 한 번 반영한다. 성공이면 판매를 처리하고, 거절이면 판매 없이 종료·퇴장한다.
개발 확인 예시 — 정가 합계 B = 1,000
평범 성인: P=1,300 → 성공·-1 / P=1,301 → 거절·-2.
가격 민감 성인: P=999 → 거절·-2 / P=1,000 → 성공·0 / P=1,001 → 거절·-2.
가난 성인: P=720 → 성공·+6 / P=900 → 성공·0 / P=1,150 → 성공·-6 / P=1,151 → 거절·-6.
절박 아이: P=1,400 → 성공·-12 / P=1,500 → 성공·-15 / P=1,501 → 거절·-15.
위 거래 상한·구간별 점수·연령 배율·거절 점수는 재결정 대상이 아니다. 남은 결정은 도덕성 시작값과 딸 반응의 단계 경계·구체 표현 등 위 사용처 절에 명시한 항목이다.
