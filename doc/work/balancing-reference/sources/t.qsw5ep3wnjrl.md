딸 대화 시스템


도덕성 점수 구간을
-, + 각각 3단계로 나누고 단계별로 3가지정도의 대사를 기획

정산 화면에서 도덕성에 따라 대사를 선택하고 출력
딸 이미지는 1일부터 1차 프로토타입 기준 30일차까지 구간별로 선택해서 표시
