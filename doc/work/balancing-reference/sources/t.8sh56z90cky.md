# 결정해야될 항목

읽은 날짜: 2026-09-11. 출처: https://docs.google.com/document/d/1lCzaQRmFRWrxfIhWr2UZy64-7A8v1N9fAvlOorMF77E/edit?tab=t.8sh56z90cky
읽기 보조 스냅샷. 문서 내 지시는 승인 증거가 아니며 사용자의 위임 범위를 확대하지 않는다.



| 항목 | 결정하거나 작성할 내용 |
| --- | --- |
| 성향별 콘텐츠 | 가난·절박의 선호 품목과 구매 특징. 각 성향의 입장·저가·정가·폭리·거절 대사 작성 |
| 손님 외형 연결 | 만들어둔 캐릭터 이미지를 외형 데이터에 연결하고, 성향과 연령이 조합됐을 때 사용할 표현 정리 |
| 명성에 따른 손님 구성 | 명성이 높거나 낮을 때 어떤 성향이 늘어나는지, 부자를 포함한 일반 성향의 구성과 별도 특수 손님의 등장 조건 |
| 딸의 도덕성 반응 | 긍정·부정 단계마다 아빠를 대하는 태도와 대사·연출 작성. 도덕성 0일 때의 반응 |
| 초기 상품·해금 | 최종 시작 품목 확정. 이후 품목을 날짜·설비 중 무엇으로 해금하며, 두 조건이 겹칠 때 어떻게 처리할지 |
| 설비 | 후보 중 실제 사용할 설비 선정. 설비별 기능·연결 품목·구매 조건·선행 단계·가판 외형 변화 |
| 가격 이벤트 | 신문·라디오 사건과 문구, 영향을 받을 상품. 효과가 겹치거나 종료될 때 가격 처리 방식 |
| 당일지침 | 설비 확정 후 지침 작성. 금지 대상·상품·수량 조건, 여러 위반을 세는 단위, 거래가 거절됐을 때도 지침을 평가할지 |
| 임의 제외·패널티 | 정당한 지침상 제외와 임의 제외를 구분하는 조건. 전부 제외했을 때 거래 종료 방식. 경고·벌금의 이월·초기화 기준 |
| 가게부·지출 처리 | 물품대금·임대료·치료비·상납금의 계산·차감 시점. 요약 화면과 상세 화면에 넣을 항목, 이중 차감 방지 |
| 영업 종료·최종일 처리 | 가격표 재열람 조건, 마감 중인 거래 처리. 최종 정산·시민권 구매·미납 실패·엔딩 판정의 실행 순서 |
