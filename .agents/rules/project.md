# Cashier 공통 작업 입구

사람과 AI 작업자는 도구에 관계없이 같은 저장소 규칙을 따른다.

1. 모든 작업 전에 [공통 작업 규칙](../../doc/WORK_RULES.md) 파일을 읽고 적용한다.
2. [문서 색인](../../doc/INDEX.md)에서 작업에 해당하는 명세만 선택해 읽는다. 모든 문서를 항상 읽지는 않는다.
3. 코드 수정 시 [프로그래머·기술 규칙](../../doc/CODING_RULES.md)을 반드시 함께 읽는다.
4. 담당 전환·중단 시 [작업 인계 기준](../../doc/work/README.md)을 참고한다. 담당자는 사람 기준으로 기록하고 도구·세션 링크는 보조 정보로 사용한다.

승인·보호·검증 규칙의 단일 본문은 위 문서에 있다. 도구별 입구에 복제하거나 별도 권한으로 해석하지 않는다.
